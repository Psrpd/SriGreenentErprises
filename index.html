Azure Developer Interview Questions & Answers

1. Azure Fundamentals

Q1. What is Microsoft Azure?
Azure is a cloud computing platform by Microsoft that provides services like computing, storage, networking, databases, analytics, and DevOps.
Q2. What are IaaS, PaaS, and SaaS?
IaaS – Infrastructure (VMs, storage)
PaaS – Platform (App Service, Azure SQL)
SaaS – Software (Office 365, Outlook)
Q3. What is a Resource Group?
A Resource Group is a logical container that holds related Azure resources.

Example: Web App + SQL + Storage inside one resource group.

2. Azure Compute Services

Q4. What is Azure Virtual Machine?
Azure VM allows you to run Windows or Linux servers in the cloud.

Example: Hosting legacy applications.
Q5. What is Azure App Service?
Azure App Service is a PaaS service to host web apps, APIs, and mobile apps.

Example: Hosting ASP.NET Core or Angular apps.
Q6. What is Azure Function?
Azure Functions is a serverless compute service that runs code on demand.

Example: Send email when a file is uploaded. 
public static void Run(
  [BlobTrigger("files/{name}")] string content)
{
    // process file
}

3. Azure Storage

Q7. Types of Azure Storage?
Blob, File, Queue, Table, Disk Storage
Q8. What is Azure Blob Storage?
Used for storing unstructured data like images, videos, documents.

Example: Profile images upload.

4. Azure Database Services

Q9. What is Azure SQL Database?
Fully managed relational database service based on SQL Server.
Q10. What is Azure Cosmos DB?
A globally distributed NoSQL database with low latency.

APIs: Core (SQL), MongoDB, Cassandra, Table, Gremlin

5. Azure Networking

Q11. What is Azure VNet?
Virtual Network allows Azure resources to communicate securely.
Q12. What is NSG?
Network Security Group controls inbound and outbound traffic.

6. Azure Security

Q13. What is Azure Active Directory?
Identity and access management service for authentication and authorization.
Q14. What is Azure Key Vault?
Securely stores secrets, keys, and certificates.

Example: Connection strings.

7. Azure DevOps

Q15. What is Azure DevOps?
A set of tools for CI/CD, code management, testing, and deployment.
Q16. What is CI/CD?
CI: Continuous Integration
CD: Continuous Deployment
Q17. Example of Azure DevOps YAML Pipeline
trigger:
- main

pool:
  vmImage: 'windows-latest'

steps:
- task: DotNetCoreCLI@2
  inputs:
    command: 'build'
    projects: '**/*.csproj'

8. Scenario-Based Questions

Q18. How to host a highly available web app?
Use Azure App Service + Load Balancer + Availability Zones + Auto Scaling.
Q19. How do you reduce Azure cost?
Auto-scaling, Reserved Instances, Storage tiers, Monitoring.
Q20. How do you secure APIs in Azure?
Azure API Management + Azure AD authentication + HTTPS.
